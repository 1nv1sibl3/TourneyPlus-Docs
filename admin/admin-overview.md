## Admin Principles

- Keep moderation decisions explicit (ban/suspend with reasons).
- Keep dashboard and bot behavior synchronized.
- Avoid destructive actions without verifying cross-event dependencies.
- Prefer state-aware UI actions over direct DB-only operations.

## Quick Daily Checklist

1. Check system health cards.
2. Review recent jobs and failures.
3. Review subscription usage anomalies.
4. Check billing/email actions.
5. Scan server monitor for disconnected/problem servers.
