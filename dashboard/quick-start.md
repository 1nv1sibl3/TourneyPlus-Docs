# Quick Start

## 1. Login and Select Server

- Login with Discord.
- Confirm you are in the correct server context.
- Check plan status in Profile.

## 2. Create Event

- Scrim: `/scrims/config`
- Tournament: `/tournaments/create`
- Single Match: `/matches`

## 3. Open Registration

Open registration from event controls and verify the registration message is posted in Discord.

## 4. Fill Slots

Track slot updates and confirm teams are assigned correctly.

## 5. Run Match Result Flow

- Schedule match if required.
- Open screenshot window if using screenshot flow.

Then pick the mode based on your plan:
- **AI-enabled**: review parsed rank/kills in Results Hub/leaderboard editor.
- **No AI**: enter rank/kills manually in leaderboard editor.

## 6. Review and Publish

- Resolve conflict warnings first.
- Publish leaderboard to Discord.

## 7. Close Event Stage

- Close registration when done.
- Archive/delete event as needed.
