# Quick Start

## Step 1: Login and Server Context

- Login with Discord.
- Confirm you can access the intended server.
- Check current subscription status in Profile.

[IMG: Login + first dashboard load]

## Step 2: Create Event

- Scrim: `/scrims/config`
- Tournament: `/tournaments/create`
- Single Match: via Matches/Single Match flow

Use clear naming and verify channels/roles before opening registration.

## Step 3: Open Registration

From the event manager page, open registration and verify the registration announcement is posted in Discord.

## Step 4: Monitor Slot Fill

Track slot fill from event page and slot list updates.
If slots look stale after restarts, confirm persistent views/state is restored on bot startup.

## Step 5: Schedule and Process

- Schedule match(es)
- Open screenshot window for the selected match/group
- Watch queue status and process results

## Step 6: Review Conflicts and Publish

- Check conflict panel in processing UI.
- Resolve duplicate-rank or unreadable-kill cases.
- Publish leaderboard only after confirmation.

[IMG: Publish confirmation warning example]

## Step 7: Closeout

- Close registration when complete.
- Archive or delete event from manager flow.
- Use admin analytics/tracker for usage reporting.
