# Glossary

- **Registration**: period when teams can submit entries.
- **Slot**: assigned team position in an event.
- **Group**: bracket bucket like A/B/C.
- **Required Mentions**: number of player tags required per registration message.
- **Screenshot Window**: period where screenshot submissions are accepted.
- **Results Hub**: screen used to review and edit parsed/manual results.
- **Rank**: placement captured from the match result screen.
- **Kill Point**: points from kills.
- **Position Point**: points from rank mapping.
- **Total Points**: `Kill Point + Position Point`.
- **Conflict**: warning state such as duplicate rank or uncertain result field.
- **Server Scope Plan**: subscription bound to one server.
- **User Scope Plan**: subscription bound to user account.
